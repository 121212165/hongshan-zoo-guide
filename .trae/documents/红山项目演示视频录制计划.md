# 红山项目演示视频录制计划

## Summary（摘要）

为「红山朋友 · 陪逛 Agent」项目录制一支演示视频，完整展示两块核心能力：
1. **evals 金标集评测**：跑 `npm run eval`（stub 模式，50 题，离线确定性），展示门禁通过 + 报告产出
2. **前端 Demo**：`pnpm dev` 启动应用，演示路线规划 / 陪逛 / 手账 / 浮动导游全流程

采用**全离线 stub 模式**作为演示主路径（无需 API key、零成本、确定性、无网络风险），事实题在前端会优雅降级到档案卡模板。录屏工具用开源的 **OBS Studio**（零安装备选 Xbox Game Bar）。

### Step 3：启动前端 Demo（演示主体 B）

## Assumptions & Decisions（假设与决策）

1. **决策：演示走全离线 stub 模式**
   - 理由：stub 模式确定性、零成本、无网络/限流风险，门禁已验证通过（avg 1.93）
   - 代价：前端事实题讲解会降级到 `c.say[persona]` 模板（比 LLM 生成略简短），但立场/边界/路线题完全正常
   - 备选：若想要真实 LLM 效果，执行时按 [app/.env.example](file:///c:/Users/lenovo/Desktop/Kimi_Agent_红山导览方案/app/.env.example) 填 `LLM_API_KEY` 并设 `LLM_GATEWAY_MODE=live`，改跑 `npm run eval:hybrid`

2. **假设：`pnpm` 已全局可用**
   - CI 用 `pnpm@10`（见 [eval-gate.yml](file:///c:/Users/lenovo/Desktop/Kimi_Agent_红山导览方案/.github/workflows/eval-gate.yml#L44)）；本地若无 pnpm，`npm install -g pnpm@10`
   - 退化方案：若不想装 pnpm，可 `npm install` + `npm run eval` / `npm run dev`（package.json 脚本用的是 `npm run`，不依赖 pnpm）

3. **决策：不修改任何业务代码**
   - 仅运行现有脚本，不碰 `evals/`、`app/src/` 源码
   - 唯一可能创建的文件：若用户选择 LLM 模式，则创建 `app/.env`（从 `.env.example` 复制并填 key）

4. **假设：OBS Studio 由用户自行下载安装**
   - 我不自动安装录屏软件；提供下载链接和配置要点
